分布函数
全称：Cumulative Distribution Function

分布函数是概率论中的“万能工具”，无论是离散型还是连续型随机变量，都可以用它来完全描述。

  • 定义：设 XXX 是一个随机变量，对于任意实数 xxx，分布函数定义为随机变量 XXX 落在区间 (−∞,x](-\infty, x](−∞,x] 内的概率：

F(x)=P(X≤x)F(x) = P(X \le x) F(x)=P(X≤x)

  • 直观理解：它是一个“累积器”。你拿着一个袋子从数轴的左边 −∞-\infty−∞ 一路向右走，走到 xxx 点时，袋子里收集到的所有概率的总和，就是 F(x)F(x)F(x)。

  • 三大核心性质：

  1. 单调不减：你往右走，收集到的概率只会变多或不变，绝不会变少。（x1<x2⇒F(x1)≤F(x2)x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)x1​<x2​⇒F(x1​)≤F(x2​)）

  2. 有界性：在极左边，什么都没收集到（F(−∞)=0F(-\infty) = 0F(−∞)=0）；走到极右边，收集完了所有的概率（F(+∞)=1F(+\infty) = 1F(+∞)=1）。

  3. 区间概率计算：想要知道 XXX 落在区间 (a,b](a, b](a,b] 的概率，只需要做个减法：P(a<X≤b)=F(b)−F(a)P(a < X \le b) = F(b) - F(a)P(a<X≤b)=F(b)−F(a)。

概率密度函数
全称：Probability Density Function

密度函数是连续型随机变量专属的工具。

为什么需要它？因为对于连续型随机变量来说，取任何一个孤立具体值的概率都为 0（即 P(X=a)=0P(X=a) = 0P(X=a)=0）。这就好比问：“一条线段中，某一个数学意义上没有长度的点，占整条线段的多少？”答案是 0。因此，我们要研究的是它在某个区间内“密集”的程度。

  • 定义：如果存在一个非负函数 f(x)f(x)f(x)，使得对于任意实数 xxx，都有：

F(x)=∫−∞xf(t)dtF(x) = \int_{-\infty}^{x} f(t) dt F(x)=∫−∞x​f(t)dt

那么 f(x)f(x)f(x) 就是随机变量 XXX 的概率密度函数。

  • 直观理解：它就像物理中的“线密度”。在某一点 xxx 周围切一小段 Δx\Delta xΔx，这一小段包含的“概率质量”近似为 f(x)Δxf(x)\Delta xf(x)Δx。

  • 两个关键警示（极其容易踩坑的地方）：

  1. f(x)f(x)f(x) 不是概率！ 它是概率的密度。概率必须 ≤1\le 1≤1，但密度函数的值 f(x)f(x)f(x) 完全可以大于 1。（只要它与横轴围成的总面积为 1 即可）。

  2. 性质：f(x)≥0f(x) \ge 0f(x)≥0，且整个实数轴上的积分为 1（∫−∞+∞f(x)dx=1\int_{-\infty}^{+\infty} f(x) dx = 1∫−∞+∞​f(x)dx=1）。

如果你将这两者联系起来，就会发现它们不过是微积分基本定理在概率论中的倒影：

  1. 积分关系：分布函数 F(x)F(x)F(x) 是密度函数 f(x)f(x)f(x) 从 −∞-\infty−∞ 到 xxx 的定积分（面积）。

  2. 求导关系：在 f(x)f(x)f(x) 连续的那些点上，密度函数是分布函数的导数：

f(x)=F′(x)f(x) = F'(x) f(x)=F′(x)
