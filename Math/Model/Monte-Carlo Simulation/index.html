# Core

核心
假设有一个随机变量：XXX

我们想计算：E[X]E[X]E[X]

但是直接计算很困难。

于是随机生成：

X1,X2,⋯ ,XNX_1,X_2,\cdots,X_N X1​,X2​,⋯,XN​

那么可以使用：

μ^=1N∑i=1NXi\hat\mu = \frac1N\sum_{i=1}^N X_i μ^​=N1​i=1∑N​Xi​

来估计：

μ=E[X]\mu=E[X] μ=E[X]

这就是 Monte Carlo 最核心的公式：

E[X]≈1N∑i=1NXiE[X] \approx \frac1N\sum_{i=1}^N X_i E[X]≈N1​i=1∑N​Xi​

换句话说：

Monte Carlo Simulation 本质上就是用大量随机样本的平均值来估计理论上的期望值。

# Monte Carlo Error

Monte Carlo 的误差

这是学习 Monte Carlo 时非常重要的一部分。

假设：

Y=f(X)Y=f(X) Y=f(X)

我们用：

μ^=1N∑i=1NYi\hat\mu = \frac1N \sum_{i=1}^NY_i μ^​=N1​i=1∑N​Yi​

估计：

μ=E[Y]\mu=E[Y] μ=E[Y]

如果：

Var(Y)=σ2Var(Y)=\sigma^2 Var(Y)=σ2

那么样本均值的方差：

Var(μ^)=σ2NVar(\hat\mu) = \frac{\sigma^2}{N} Var(μ^​)=Nσ2​

所以标准差：

SD(μ^)=σNSD(\hat\mu) = \frac{\sigma}{\sqrt N} SD(μ^​)=N​σ​

这个量就是 Monte Carlo 误差的核心。

# Confidence Intervals

Monte Carlo 的置信区间

假设：

μ^=1N∑Xi\hat\mu = \frac1N\sum X_i μ^​=N1​∑Xi​

如果 NN 足够大，根据中心极限定理：

μ^≈N(μ,σ2N)\hat\mu \approx N\left( \mu, \frac{\sigma^2}{N} \right) μ^​≈N(μ,Nσ2​)

因此：

SE=sNSE = \frac{s}{\sqrt N} SE=N​s​

其中 ss 是样本标准差。

大约 95% 置信区间：

μ^±1.96sN\hat\mu \pm 1.96\frac{s}{\sqrt N} μ^​±1.96N​s​

这就是 Monte Carlo 和你上一条问的中心极限定理之间的重要联系。
