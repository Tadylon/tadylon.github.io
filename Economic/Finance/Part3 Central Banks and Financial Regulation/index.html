中央银行与金融监管

# Central Bank

# Generated

中央银行产生的客观经济基础

  • 统一的银行券发行和流通
  • 票据交换和债务债权清算
  • 商业银行稳定和可持续发展
  • 金融监管以及金融和经济秩序稳定

# System

中央银行体系性质

composite central banking system
复合的中央银行制度：在一个国家内，没有专职的中央银行，而是和专门银行兼任

single central bank system
单一的中央银行制度：国家单独设立中央银行机构

System Implementation
一元的中央银行制度 在一国内设立一家中央银行，采取总分行制
二元的中央银行制度 在中央和地方分别设立两级中央银行机构

Transnational Central Banking Systems
跨国的中央银行制度：由参加某一货币联盟的所有成员国家共同组成

Quasi-central bank system
准中央银行制度：设立类似于中央银行的机构，执行央行部分职能

# Natural

中央银行是具有银行特征的国家机关性质

是国家机关，全国金融事业的最高管理机构
负责制定和组织执行货币金融政策
要办理存款，贷款，结算业务
以拥有的经济力量对经济活动进行调节可控制

# Functions

# Issuing Bank

中央银行是发行的银行：唯一发行法定货币的机构

# Bank of Banks

银行的银行

  • 集中商业银行的存款准备金
  • 向商业银行发行贷款
  • 办理商业银行之间的清算

# Government-owned banks

政府的银行

  • 代理国库
  • 为国家持有和经营国际储备资产
  • 在国际金融交往过程中，建立业务联系，处理国际金融事务
  • 为政府弥补财政赤字提供融资

# Balance Sheet

资产负债表

# Liabilities

负债项目

  • 流通中的现金（所占比重最大
  • 各项存款（主要是商业银行存款
  • 其他负债
  • 资本项目（中央银行的自有资本

# Asset items

资产项目

  • 贴现及贷款
  • 各种证券
  • 黄金外汇储备
  • 其他资产（土地，设备，代收款

# Business

负债业务

  • 货币发行业务
  • 存款业务：商业银行存款准备金，政府财政部存款，外国存款，其他
  • 国际金融机构负债
  • 国内金融机构往来
  • 兑付国库券基金

资产业务

  • 再贴现业务
  • 贷款业务：对商业银行放款，对财政的放款，其他
  • 债券买卖业务
  • 保管黄金外汇储备

其他业务

  • 资金清算业务
  • 代理国库业务

# Financial Regulation

市场准入和准出管理

价格限制：最高存款利率，最低存款利率，最低手续费

资产流动性管理

资本重组度管理

行为方式管理

保护性管理

  • 最后贷款人制度：商业银行清偿发生较大困难时，央行提供紧急资金援助
  • 存款保险制度：参保银行可以得到资金援助
