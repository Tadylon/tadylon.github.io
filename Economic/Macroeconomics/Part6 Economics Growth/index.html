# Doma Model

投资有双重影响

  • 需求效应：净投资通过乘数作用扩大收入和就业
  • 供给效应：投资增加新的生产能力

生产能力增长 ΔY=δI\Delta Y = \delta IΔY=δI
总收入增长 其中边际储蓄倾向 a=ΔSΔYa = \frac{\Delta S}{\Delta Y}a=ΔYΔS​ , 1a\frac{1}{a}a1​ 称为投资乘数

ΔY=1a⋅ΔI\Delta Y = \frac{1}{a} \cdot \Delta I ΔY=a1​⋅ΔI

多马模型的投资增长
充分就业均衡增长应该有上述两式相等

ΔII=aδ\frac{\Delta I}{I} = a \delta IΔI​=aδ

# Model Feature

两个模型实质上是一致的

优点：

  • 发展了凯恩斯理论，使其长期化，动态化
  • 强调资本积累率（储蓄率）在经济发展中的决定性作用
  • 支出企业投资不足时，国家干预和宏观调控的必要性
  • 提供了观察分析经济增长的方法工具，常用于预定经济增长目标

缺点：

  • 假定 资本-产出率 不变
  • 假定 资本与劳动之间的不可替代率

# Neoclassical Economic Growth Models

新古典经济增长模型

# Basic Assumption

  • 所有商品价格完全具有弹性
  • 资本和劳动力存在替代关系
  • 充分就业均衡可以随时达到，实际产出等于潜在产出
  • 只生产一种商品，及用于消费，也用于投资
  • 储蓄就是投资，储蓄率固定不变

# Functions

总收入是生产要素的函数

Y=F(K,L)Y = F(K,L) Y=F(K,L)

经济增长率

ΔYY=αΔKK+βΔLL\frac{\Delta Y}{Y} = \alpha \frac{\Delta K}{K} + \beta \frac{\Delta L}{L} YΔY​=αKΔK​+βLΔL​

α\alphaα,β\betaβ 表示资本和劳动对总收入的弹性

经济增长率不仅取决于投资量，而且依赖于各自的产出弹性

调节 资本-劳动的投入比例 ，就能够调节 资本-产出比率

# Rebulid

索罗 - 米德模型
Rebuild Basic Assumptions

  • 生产要素的收入等于边际产品
  • 总量生产书的变化是线性的
  • 技术变化是中性的，不改变资本与劳动的边际替代率

新古典经济增长模型

Y=A⋅F(K,L)Y = A \cdot F(K,L) Y=A⋅F(K,L)

乘数因子：A=A(t)A = A(t)A=A(t) 表示技术进步随时间的积累效果
经济增长模型

ΔYY=αΔKK+βΔLL+ΔAA\frac{\Delta Y}{Y} = \alpha \frac{\Delta K}{K} + \beta \frac{\Delta L}{L} + \frac{\Delta A}{A} YΔY​=αKΔK​+βLΔL​+AΔA​

技术进步的贡献称为索洛余值 \text

ΔAA=ΔYY−αΔKK−βΔLL\frac{\Delta A}{A} = \frac{\Delta Y}{Y} - \alpha \frac{\Delta K}{K} - \beta \frac{\Delta L}{L} AΔA​=YΔY​−αKΔK​−βLΔL​

# Economic Growth Model

The New Cambridge School’s Economic Growth Model
新剑桥学派经济增长模型

\begin{align} Y &= P + W \\ S_P &> S_W , S_W \approx 0 \\ S &= P \cdot S_P + W \cdot S_W \\ \end{align}

Cambridge Function

G=sv=PY×SP×YK=PK×SPG = \frac{s}{v} = \frac{P}{Y} \times S_P \times \frac{Y}{K} = \frac{P}{K} \times S_P G=vs​=YP​×SP​×KY​=KP​×SP​

  • 间陆离利润率和经济增长之间的正比例关系
  • 长期均衡经济增长可通过调节分配，改变利润率来实现
  • 只有资本家阶级的储蓄行为对经济增长具有绝对意义

# Robinson’s Model

Robinson’s Model of Capital Accumulation
罗宾逊资本积累模型

经济增长主要机制是利润率，若预期利润率与可实现利润率相当，则经济稳定增长
过去的投资决定现在的利润率，进而影响未来的利润率的预期，决定目前的投资策略

可实现利润率曲线AAA 与资本积累函数III，的交点表示均衡，其中只有一个稳定均衡
AAA：各种资本积累率能实现的利润率，为直线
III：各种预期利润率可能的计划资本积累率
利润率的变动有一个有效区间

  • 最低由企业的垄断程度决定
  • 最高由现存分配关系决定（通货膨胀关口）

两种增长率：

  • 理想的资本积累率：通过利润率引致的资本积累
  • 可能的经济增长率：技术进步和劳动力增长觉得的增长率，也成为自然增长率

两种增长率相等时。经济就会出现增长的黄金时代

  • 工资与劳动产出率同步增长
  • 技术进步

如果利润中消费为 0，则适合经济增长的资本存量全部用于吸引劳动就业，称为黄金时代

假设技术水平 AAA 为正，人口增长率为零，广义资本是决定生产的唯一要素，边际产出不变，若不考虑人口因素，一个国家的收入水平由技术水平和广义资本决定。

Basic Assumption

  • 技术变动是内生决定的
  • 只是或者思想还可以不菲成本的重复使用（事实上新思想可具有部分排他性）

# Economic Cycle

经济周期

# Definition

总体经济

总体经济运行中不规则德经济扩张与经济紧缩交替更迭反复出现的波动现象

Feature

  • 是总体经济活动的波动而不是某一个具体经济变量的波动
  • 一般划分为扩张和衰退两个过程
  • 一致性：扩张和衰退总是同时在许多经济活动中发生的
  • 循环性：经济周期不具有规律，可预测的周期，但是总是循环出现
  • 持续性：经济周期的时间存在较大差别，但是一般会持续一段时间

# Framework for Analysing

经济周期分析框架

影响宏观经济的重要因素回事引起总供给或者总需求的变动，这些事件或者扰动称为经济冲击

总需求冲击
如果总需求曲线向右移动，短期价格不变，产出上升；长期价格上升，产出恢复

总供给冲击
如果总供给曲线向左移动，价格上升，产出下降

# Classical Economic Cycle

古典经济周期理论

# RBC

实际经济周期理论
实际冲击：对经济的实际方面发生的扰动，影响IS Curves, FE Curves\text{IS Curves, FE Curves}IS Curves, FE Curves
名义冲击：对货币供给或者需求的冲击，影响 LM Curves\text{LM Curves}LM Curves
RBC 经济学家认为，技术冲击是最重要的冲击，也成为供给冲击，引起生产函数变化

# Reverse Engineer

逆向技术冲击的影响

  • 劳动边际产品下降，对劳动的需求下降
  • 均衡的工资水平和就业量下降， FE Curves\text{FE Curves}FE Curves 左移，产出下降
  • 资本市场迅速调整，价格升高， LM Curves\text{LM Curves}LM Curves 左移
  • 新的均衡沿着 IS Curves\text{IS Curves}IS Curves 发生移动，消费和投资下降，实际利率升高

技术冲击的规模可以用索洛余值来进行衡量
索洛余值不仅反映技术变化，资本，劳动的利用率也会影响索洛余值
资本和劳动的利用率都是顺周期的
企业在衰退期倾向于降低公认的工作强度，而不是解雇工人，这一现象称为劳动储备

# Fiscal policy shocks

财政政策冲击
如果政府购买增加

  • 扩张的财政政策使 IS Curves\text{IS Curves}IS Curves 右移
  • 政府支出增加使居民财富减少，劳动供给曲线右移，均衡的劳动数量增加，实际工资下降
  • FE Curves\text{FE Curves}FE Curves 右移，偏离一般均衡，总需求超过总产出
  • LM Curves\text{LM Curves}LM Curves 左移，达到新的一般均衡，总产出和实际利率都升高

认为时滞的存在使经济稳定政策很难成型

  • 识别时滞
  • 行动时滞
  • 生效时滞

# Failure

不能解释经济衰退期之后，通货膨胀相对滞后
