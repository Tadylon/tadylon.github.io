在使用 Git 之前，需要先进行身份配置，这样提交记录才能关联到你的账号。

命令 描述 示例
git --version 查看 Git 版本，确认是否安装成功 git --version
git config --global user.name "<name>" 设置全局用户名 git config --global user.name "Your Name"
git config --global user.email "<email>" 设置全局邮箱地址 git config --global user.email "your.email@example.com"
git config --list 查看当前所有配置 git config --list
