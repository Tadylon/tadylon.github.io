# 实用小工具指令

指令 用途
cmake --version 查看当前安装的 CMake 版本。
cmake --help 查看所有支持的参数。
cmake -L .. 列出当前项目所有可配置的变量（比如路径、开关）。
cmake --build . --target clean 清理编译生成的中间文件，但不删除配置。
